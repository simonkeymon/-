# 风格规范 · 工程蓝图（Blueprint）

整部影片视为一套 **12 张工程图纸**，每一幕就是一张图纸（SHEET 01–12）。

## 色板
| 用途 | 色值 |
|---|---|
| 图纸底色 | `#0f3f86`（中心略提亮的径向渐变） |
| 网格：粗线 120px / 细线 24px | 白色，不透明度 18% / 7% |
| 线稿、正文 | `#eaf3ff` |
| 手写批注、当前年份高亮 | `#ffe27a` |
| 次要标注 | `#eaf3ff`，不透明度 70% |

只用这三种颜色，不引入其他颜色。

## 字体
| 角色 | 字体 |
|---|---|
| 中文标题 / 正文 | Noto Sans SC（700 / 500 / 300） |
| 年份、英文标注、编号 | IBM Plex Mono（600 / 400），年份用空心描边 |
| 手写批注 | 马善政毛笔楷书 Ma Shan Zheng（仅黄色） |

## 版式（1920×1080，每张图纸通用）
- 双线图框：外框 40px 边距，粗 3px；内框 52px 边距，粗 1px
- 左上角：`DWG. AI-HIST / SHEET NN OF 12 — 章节名`
- 左栏（x 96–760）：空心年份 → 标题 → 黄色手写批注 → 虚线框“设计说明”（SPEC）
- 右侧绘图区（x 760–1840，y 110–770）：本幕的原理图或示意图
- 左下角：贯穿全片的时间轴（12 个刻度，当前年份用黄圈标出）
- 右下角：图纸标题栏，填写本幕的图号、设计者（关键人物）和地点

## 固定组件
模块框（中文 + 英文等宽字）、带箭头的直角连线、尺寸标注线、虚线引出线接手写批注、齿轮、图表坐标轴。

## 运动规则
- **绘制**：所有线条按“画出来”的方式出现（描边动画，0.6–1.2 秒，缓出）
- **文字**：正文淡入并上移 12px；手写批注按书写方向从左往右出现
- **转场**：一条发光的扫描线从左向右扫过，擦除上一张图纸（1 秒），随后下一张开始绘制
- **呼吸感**：每一幕整体缓慢放大 1.5%，齿轮持续转动
- 画面始终不出现实拍照片，所有内容都是线稿

## 声音
合成的氛围电子乐（A 小调，96 BPM）。随章节推进逐步加层，寒冬段落收缩为低频铺底，片尾回落。每次转场配一声扫描线的“呼”声。
